# 🎯 JobHunter Wiki

Willkommen im offiziellen Wiki von **JobHunter** – einer vollständig lokalen, KI-gestützten Bewerbungsverwaltung.

> Alle Daten bleiben auf deinem Rechner. Kein Account, kein Cloud-Abo, keine Datenweitergabe.

## Was ist JobHunter?

JobHunter kombiniert eine strukturierte Bewerbungsverwaltung mit lokaler KI (via Ollama) und hilft dabei, den gesamten Bewerbungsprozess von der Stellensuche bis zum Vertragsabschluss zu begleiten – datenschutzkonform und barrierefrei.

## Kernfunktionen auf einen Blick

| Bereich | Highlights |
|---|---|
| 🔍 Stellensuche | Bundesagentur, Adzuna, StepStone, LinkedIn, Foto-Upload (OCR) |
| 🤖 KI (lokal) | Anschreiben, CV-Optimierung, Interview-Prep, Gehaltstraining, ATS-Score |
| ✉️ Anschreiben-Vorlage | Eigene DOCX-Vorlage hochladen, KI füllt sie stellenspezifisch |
| 📊 Dashboard | Kanban-Board, Live-Statistiken, Gamification, Wochenziel & Streak |
| 📧 Kommunikation | IMAP-Parser, E-Mail-Vorlagen, Kalender-Export (.ics) |
| 🏢 Firmen-Dossier | Wikipedia-basierte Firmeninfo direkt bei jeder Bewerbung |
| 📤 Import / Export | JSON, CSV, XLSX, PDF |
| ♿ Barrierefreiheit | WCAG 2.1 AA+, Legasthenie-Theme, Farbenblindheits-Filter, ADHS-Modus |
| 🔒 Datenschutz | 100 % lokal, DSGVO Art. 20, AES-256, optionales JWT |
