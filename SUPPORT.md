## English

Thanks for using JobHunter! Here’s how to get help.

---

### 🔍 Before You Ask

Please check these resources first – your question may already be answered:

- 📖 **[Installation Guide](INSTALL.md)** – step-by-step setup for all platforms
- ❓ **[FAQ](docs/faq.md)** – most common problems & solutions
- 🛠️ **[Setup Guide](docs/setup.md)** – quick start & environment variables
- 🔒 **[Security Policy](SECURITY.md)** – for security-related issues
- 🗺️ **[Roadmap](docs/roadmap.md)** – planned features

---

### 🐛 Found a Bug?

Open an **[Issue](https://github.com/freddykrueger88/JobHunter/issues/new)** with the label `bug` and include:

- Steps to reproduce
- Expected vs. actual behavior
- OS, Docker version, browser
- Relevant logs (`docker compose logs backend`)

---

### 💡 Feature Request?

Open an **[Issue](https://github.com/freddykrueger88/JobHunter/issues/new)** with the label `enhancement`.
Briefly describe the use case and why it would be useful.

---

### ❓ General Question?

Open an **[Issue](https://github.com/freddykrueger88/JobHunter/issues/new)** with the label `question`.
No question is too simple!

---

### 🔒 Security Vulnerability?

> ⚠️ Please do **NOT** report security issues publicly.

Use GitHub's confidential reporting:
**→ [Report a vulnerability](https://github.com/freddykrueger88/JobHunter/security/advisories/new)**

---

### 💬 Response Times

| Type | Expected Response |
|---|---|
| Bug | Within 48 hours |
| Feature request | Within 7 days |
| Question | Within 48 hours |
| Security | Within 48 hours (confidential) |

JobHunter is maintained as a free, open-source project. Response times are best-effort.
